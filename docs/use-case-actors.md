## Три актора (один человек в разные моменты)

| Актор | Когда |
|-------|--------|
| **Гость** | Ещё не вошёл в систему |
| **Владелец** | Вошёл и в кошельке у него роль создателя (создал кошелёк или OWNER) |
| **Пользователь** | Вошёл и приглашён в чужой кошелёк (участник) |

После **«Войти»** тот же человек работает уже как Владелец или Пользователь — отдельного актора «USER» и «ADMIN» на диаграмме не нужно.

---

## Прецеденты (без номеров UC)

### Гость
- Зарегистрироваться  
- Войти  

### Владелец и Пользователь (общее)
- Просмотреть свои кошельки  
- Добавить доход или расход  
- Разделить расход с участниками  
- Посмотреть баланс и отчёт  

### Только владелец
- Создать кошелёк  
- Пригласить по нику  
- Настроить кошелёк (бюджет, категории, автоплатёж, кто видит бюджет)  

### Только пользователь
- Удалить **свою** операцию  

Владелец может удалять **любые** операции (можно подписать у «Добавить доход или расход» или отдельным коротким овалом).

---

## Как рисовать (макет)

```
     [ Гость ]
    /         \
Регистрация   Войти
                  |
         +--------+---------+
         |                  |
    [ Владелец ]      [ Пользователь ]
         |                  |
   Создать кошелёк      (общие овалы)
   Пригласить
   Настроить кошелёк
```

Внутри прямоугольника «Система» — 8–10 овалов с **простыми названиями**, без `UC-01`, без `<<include>>`.

Автоплатёж по расписанию — **не отдельный актор**, а часть овала «Настроить кошелёк» (планировщик внутри backend).
